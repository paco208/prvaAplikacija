# Prva aplikacija

Prva mobilna aplikacija za MOA (Naloga 1: Hello World! v Android Studiu).

- TextView z besedilom, krepko pisavo in velikostjo 34sp
- Button »Klikni me«, ki prikaže Toast
- RadioGroup z izbiro spola (Male / Female)
- CheckBox za prijavo na e-novice
- Floating Action Button: klik prikaže privzeti Snackbar, dolg pritisk pa prilagojen Snackbar na sredini zaslona
